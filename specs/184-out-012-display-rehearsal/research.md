# Research: OUT-012 External Display Rehearsal

- **OUT-012-D1 Same code path.** Decision: the preview's placement is `ExternalOutputPlacement(slotWidth:slotHeight:correction:screenPixelAspect:deviceAspect:)` with the profile's size and PAR, and it is applied by a real `VisualSlotView(role: .external)`. Rationale: the acceptance compares the preview with the real output; sharing both the math and the UIKit application makes any drift impossible except in the preview's outer scale. Alternatives: drawing rectangles from the placement numbers (a second UIKit application path), rendering the slot to an image (extra work per change).
- **OUT-012-D2 Preview transform.** Decision: slot (W × H points) → preview area (A × B) with `s = min(A / (W·p), B / H)`, scale `(s·p, s)`, centred. Rationale: the preview frame takes the display's physical shape, so a placement that is round on the glass is round in the preview. Alternatives: square-pixel scale `(s, s)` (shows the pixel squeeze, which no viewer sees).
- **OUT-012-D3 PAR without a screen.** Decision: `VisualSlotView.standInPixelAspect: Double?` overrides the screen mode's value when set. The rehearsal sets the profile's PAR; the tests use it for the fake display of a profile. The OUT-004 sanitising and override rules still apply (`ExternalPixelAspect.resolved`).
- **OUT-012-D4 Content.** Decision: a test card view (source bounds filled, edges outlined) plus an optional grid layer (3 × 3 circles of radius 0.14·min side, a centre circle, a crosshair). Live visual not shown (spec Clarifications).
- **OUT-012-D5 Ending.** Decision: `ExternalDisplayCoordinator.isRehearsing` (observable) set by `beginRehearsal()`, cleared by `endRehearsal()` and in `settleConnection` for a new display; `hasExternalDisplay` mirrors settled displays. SwiftUI binds the cover to it, so a connect dismisses it.
- **OUT-012-D6 Probe.** Decision: a hidden DEBUG text `rehearsalProbe` reading `profile=WxH par=x.xx fit=… shape=… frame=WxH bars=…` from the preview slot; the VoiceOver label is the spoken description.
