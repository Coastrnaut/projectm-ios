# Contract: OUT-007 Corner Pin

- **C1 PresentationLifecycle** — `CornerPinPoint`, `CornerPin` (`identity`, `corners`, `point(_:)`, `validity`, `isValid`, `moving(_:to:)`, `nudging(_:dx:dy:)`, `nudgeStep` 0.005, `range` −0.5…1.5, `minimumArea` 0.05, `minimumTurnSine` 0.035, `stored`, `init?(stored:)`, `homography`), `Homography` (`map`, `jacobianDeterminant`, `layerMatrix(width:height:anchorX:anchorY:)`). Pure Swift, no UIKit.
- **C2 VisualSlotView** — `cornerPin` (external role: sets `layer.sublayerTransform` from the pin for the current bounds and anchor, without implicit animation, on change and in every layout; device role: always identity); `showsCalibrationCard` (the card layer between the visual and the cover).
- **C3 ExternalDisplayCoordinator** — `cornerPin` (pushed to every external slot inside the set and to newly connected slots; never deferred by the recording hold; never to the device slot); `isCalibrating` (`beginCalibration()`, `endCalibration()`); `calibrationAspect` (the display's shape, last known, else 16:9); `cornerPinSummary` "pin=<identity|custom> card=<shown|hidden> corners=<x,y;…>" for the external slot holding the visual (or the first external slot), else "none". AppCoordinator applies the stored pin at launch through `ExternalOutputSetting`.
- **C4 Settings** — `ExternalOutputSetting.cornerPin` stored under `cornerPinKey`, part of `keys`; Settings › External Display "Corner pin…" (`externalCornerPinButton`) opens `CornerPinEditorView` (handles `cornerPinHandle.<corner>`, picker `cornerPinCornerPicker`, nudge buttons `cornerPinNudge.<left|right|up|down>`, `cornerPinReset`, `cornerPinDone`).
- **C5 DEBUG probe** — with `-uitestExternalDisplay`, a hidden `externalCornerPin` element whose value is `cornerPinSummary`.
