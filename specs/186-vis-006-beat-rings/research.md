# Research: VIS-006 Beat Pulse Rings

- **VIS-006-D1 Event source.** The native host's `LiveBandAnalyzer` owns an ANL-016 pipeline that already publishes ANL-005 `beat` and ANL-007 `transient(.kick)` events to every subscription (`subscribe(eventCapacity:)`, as SHOW-011's tap tempo does). A second subscription with 64 events (the default; at most a few events per frame) is drained with `nextEvent()` on the frame loop: a value copy under the subscription's lock, no allocation. Decision: beats with confidence ≥ 0.5 (`AdaptiveBeatTracker.highConfidence`) emit; kicks emit only when the newest confident beat is more than 2 s old on the bus clock (`time.hostNanoseconds`). Session markers clear the beat memory.
- **VIS-006-D2 Birth clock.** Births use the frame context's `timeNanoseconds` (display-link target time) of the frame that drained the event. Bus and display clocks are different monotonic bases; aligning them buys ≤ 30 ms. The field is then a pure function of (births, configuration, t).
- **VIS-006-D3 Curves.** r(p) = r₀ + (r₁ − r₀)(1 − (1 − p)²), α = 0.8 · min(1, a / 0.05 s) · (1 − p)², r₀ = 0.05, r₁ = 0.95. Ease-out keeps growth visible early; the squared fade ends at zero brightness exactly at L, so removal is invisible.
- **VIS-006-D4 Flash model.** Each segment is a convex trapezoid (inner and outer arc chords); the 17-area model of `SpectrumFlashAreas` takes the color with alpha (premultiplied over the background). Rings can overlap briefly just after birth; overlap is counted twice — an overestimate, never an underestimate (as VIS-005's segments).
- **VIS-006-D5 Rate cap vs fainter rings.** A per-frame faint ring is still a 60 Hz pattern; the envelope would dim it to near black. A rate cap bounds the emission frequency itself (3/s under a rise-limited envelope, the ACC-012 profile included because it sets `riseRatePerSecond`; 6/s otherwise) and keeps each ring readable. Decision: rate cap; the envelope remains the final limit.
- **VIS-006-D6 Golden.** Four rings at ages 0.1, 0.5, 0.9 and 1.3 s (births 0, 0.4, 0.8, 1.2 s; frame at 1.3 s), default configuration, glow off, Reduce flashing off, at both golden resolutions.
