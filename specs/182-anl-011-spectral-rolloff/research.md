# Research: ANL-011 Spectral Rolloff

- **ANL-011-D1 Power, not magnitude.** Decision: P_k = m_k². Rationale: "energy percentile"; same weighting as ANL-010's centroid; noise floors barely move it. Alternatives: magnitude (librosa's default input) — sensitive to many low-level bins.
- **ANL-011-D2 In-bin interpolation.** Decision: bin k's power is spread evenly over [(k − ½)Δf, (k + ½)Δf]; rolloff = (k − ½ + (pT − S_{k−1})/P_k)·Δf for the first k with S_k ≥ pT, clamped to [0, Nyquist]. Rationale: continuous; exact for flat spectra; analytic references (spec US1) all fall within half a bin: single tone k − ½ + p; two tones 9:1 → a + 0.444, 4:1 → b − 0.25; flat bins 1…K → ½ + pK (0.85·C with C = (K + ½)Δf, the last bin's upper edge, is 0.075 bin away); power ramp P_k = k → ≈ √p·(K + ½). Alternatives: bin-centre step (whole-bin jumps); interpolation between bin centres (lone tone k − 1 + p; the 4:1 two-tone case is ¾ bin off).
- **ANL-011-D3 Bins.** Decision: reuse ANL-010's `SpectralBinRange` (20 Hz–Nyquist, DC excluded). Rationale: it was written for this row; one rule for spectral shape.
- **ANL-011-D4 Fraction.** Decision: p in [0.5, 0.99], default 0.85, validated in the configuration initializer (error `invalidFraction`). Rationale: conventional default; outside the range the value stops describing the spectrum's top or hinges on one bin. No Settings row (P2/S; no stored key).
- **ANL-011-D5 Normalization.** Decision: n = clamp(log2(f/50)/log2(20,000/50), 0, 1), fixed endpoints (configurable like the centroid's). Rationale: log like the centroid; rolloff sits higher than the centroid, so 20 kHz instead of 10 kHz; rate-independent. Alternatives: linear f/Nyquist; rate-dependent upper end.
- **ANL-011-D6 Silence.** Decision: at or below −70 dB re a full-scale sine's in-range power (Σ m²/1.5), both values 0, no signal. Rationale: the brief asks for 0; bindings smooth the drop with their release. Differs from the centroid's hold on purpose.
- **ANL-011-D7 Backends.** Decision: total via `vDSP_svesq` (Float) when Accelerate is compiled in and the backend is not `.portable`; if it is non-finite (a NaN bin) the portable Double loop (non-finite → 0) is used; the scan accumulates in Double in both. Rationale: brief asks for vDSP behind `ANALYSIS_NO_ACCELERATE`; no scratch buffer needed. If the scan ends without crossing (Float/Double rounding), the result is the last bin's upper edge, clamped.
- **ANL-011-D8 Opcode and name.** Decision: `audio.rolloff`, opcode 19 (checked free in every worktree on 2026-11-14), inspector "Rolloff".
