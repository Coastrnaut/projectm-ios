# Research: UIX-012 Touch Color Sampler

- **UIX-012-D1 Read path.** Decision: reuse REC-001's `FrameCaptureSource.captureFrame` (the next presented frame of the shown visual: compositor after effects and the FX-019 guard; native spectra and projectM as 8-bit sRGB). Rationale: it already covers every visual, is asynchronous on Metal's completion, and is what Save Frame shows. Alternatives: a new 1×1 blit into a shared buffer in `Compositor` (faster per tap but compositor-only, a new path in a file other agents edit, and nothing for projectM or the native spectra); reading the drawable (not available for ANGLE, includes OUT-009 calibration).
- **UIX-012-D2 Mapping input order.** Decision: window point → undo split (`(p − origin) / scale`, reject outside `fullSize`) → view-to-picture rect (stretch: the view; fit/fill: OUT-004's physical-aspect rule with the picture's pixel aspect) → `floor(u × width)`, far edge clamped. Rationale: matches how UIX-007 draws (render-only uniform scale at the top-left anchor plus offset) and how a Metal layer stretches its drawable. The Retina factor needs no input: the captured picture's pixel size carries it.
- **UIX-012-D3 Device fit mode.** Decision: stretch on the device. Rationale: the device drawable is the view's size × screen scale; using fit would reject edge taps whenever rounding makes the aspects differ by a fraction of a pixel. Fit and fill exist for external-style previews and are tested.
- **UIX-012-D4 Conversion.** Decision: halves → Float; clamp alpha to 0…1; a pixel with alpha 0 is black; colour = min(clamp(c), a) / a; 8-bit sRGB → linear by the inverse sRGB transfer, alpha 1. Then `ParameterColor` takes linear values, `TextColor` the sRGB-encoded ones (`FrameColorConversion.linearToSRGB`). Rationale: same clamps as REC-001's PNG path, so a sample equals the saved frame's pixel.
- **UIX-012-D5 Hit testing.** Decision: the sampling layer lives in the split host's backdrop (laid out at the full window, unscaled), so its tap location is in window coordinates; while sampling, the visualizer's other layers (`layers`) stop hit-testing; the split editor (separate) stays usable. The emergency blackout button is inside `layers` and is therefore off during sampling; Cancel ends sampling at once. (Supersedes the clarify note that blackout stays reachable.)
- **UIX-012-D6 Timeout and staleness.** Decision: a token per request; the coordinator's `timeout` is injected (tests pass a scheduler); a frame arriving after cancel, a new request or the timeout is ignored.
- **UIX-012-D7 UI test fixture.** Decision: DEBUG `-uitestColorSampleFixture <r>,<g>,<b>` (sRGB 0…255) replaces the capture source with one that returns a 4×4 opaque frame of that colour. Rationale: deterministic on simulators (no audio or GPU timing), while the GPU test proves the real read-back.
