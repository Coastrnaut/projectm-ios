# Contract: REC-010 Recording library

- **C1 Keep** (`VideoRecordingCoordinator.keepOffered()`): moves `offered` into the library folder (created if missing) under its own name, or "<stem> 2.mp4", "<stem> 3.mp4"… when taken; on success `offered = nil`, notice "Recording kept in Recordings.", the kept hook is called; on failure the recording stays offered with the writer-failure notice. Button "Keep" (identifier `recordingResultKeep`, label "Keep the recording in Recordings") on the recording panel only.
- **C2 Scan** (`RecordingLibraryStore.scan()`): non-hidden regular files of the folder; missing folder → empty; ordered by modification date descending, then name descending.
- **C3 Row facts and thumbnails** (`RecordingLibraryInspector`): facts per research D4; thumbnail per D5; both off the main actor; second request for the same key served from memory or disk without decoding.
- **C4 Delete** (`RecordingLibraryModel.requestDelete(_:)`, `confirmDelete()`, `cancelDelete()`): request sets `pendingDelete`; confirm removes the file, the row (same main-actor update), the cache entry, announces "Recording deleted."; a missing file still removes the row; Cancel removes nothing. Alert "Delete Recording?" with message "“<name>” will be deleted from this device. This can't be undone." and buttons Delete (destructive, identifier `recordingLibraryConfirmDelete`) and Cancel.
- **C5 Rename** (`RecordingLibraryStore.validate(name:excluding:)`, `rename`): research D7 rules and texts; success announces "Recording renamed.".
- **C6 Play and Share**: Play presents an AVKit player for the file; Share… presents `ActivitySharePresenter` with the file (excluded: Save to Photos, Assign to Contact).
- **C7 Storage and erase**: `StorageCategory.savedRecordings` ("Saved recordings", root `Application Support/RecordingLibrary`, not cleanable); `.recordings` reads "Unsaved recordings"; `LibraryEraseCategory.recordings` ("Saved recordings", folder `RecordingLibrary`).
- **C8 Screen identifiers**: the FILE-009 "Saved recordings" row `storage.savedRecordings` is the link (Settings › Storage; its value stays the size, and Storage remeasures when the screen comes back); summary `recordingLibrarySummary` (label "<n> recordings, <size>", or "No saved recordings"); rows `recordingLibraryRow` with label per spec Clarifications; row buttons `recordingLibraryPlay`, `recordingLibraryShare`, `recordingLibraryRename`, `recordingLibraryDelete`. DEBUG `-uitestRecordingLibrarySeed <n>` empties the library folder and writes n generated recordings (1 s apart in date) at launch.
