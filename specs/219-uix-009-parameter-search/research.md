# Research: UIX-009 Parameter Search

- **UIX-009-D1 Where the search lives.** Decision: `ParameterSearch` in ParameterGraph, over `[ParameterDescriptor]`. Rationale: pure, Linux-tested, reusable by MIDI/OSC learn later; its signature has no selection input, which makes R1 structural. Alternatives: an app-only function (not Linux-tested); a VisualParameters helper (ties search to one catalog).
- **UIX-009-D2 Normalisation.** Decision: reuse the PRE-001/PRE-003 folding (`folding(options: [.caseInsensitive, .diacriticInsensitive, .widthInsensitive], locale: nil)`), as PresetTags, SceneFolders and SceneSwitcher do; split the query on whitespace. Rationale: one behaviour across the app's searches. Alternative: `localizedStandardContains` (locale-dependent, harder to rank).
- **UIX-009-D3 Ranking.** Decision: each word gets the best tier it reaches — 0 name prefix (the folded name starts with the word), 1 name substring, 2 group (display name or ID substring), 3 unit (a unit term starts with the word); a parameter's rank is (worst word tier, sum of tiers, catalog index), ascending. Rationale: a query whose every word hits the name outranks one that leans on the unit; stable ties. Alternative: fuzzy scoring (unpredictable for VoiceOver users, needless for 15 items).
- **UIX-009-D4 Unit terms.** Decision: none → no terms; normalized → "percent", "%"; fractionOfOutput → "percent", "%", "fraction", "of output"; seconds → "seconds", "sec", "s", "ms", "milliseconds", "time"; perSecond → "per second", "/s", "hz", "hertz", "rate"; degrees → "degrees", "deg", "°", "angle"; count → "count", "number", "#". Rationale: the inspector shows % for both fractional units and s, /s, ° for the others; "ms" and "Hz" are what people type for time and rate. A multi-word term ("per second") matches a query word against each of its words' prefixes as well as the whole term.
- **UIX-009-D5 Entry point.** Decision: a `ParameterSearchLinkSection` in `SettingsView.mediaSections` right before Modulation (`.id("parameterSearch")` for `-uitestSettingsSection`); the pushed view calls back into SettingsView's `inspectParameter`, so the existing UIX-003 sheet (and its UIX-004 Pin to Shelf) opens. Alternative: a search field at the top of Settings (crowds the root list, collides with other agents' edits).
- **UIX-009-D6 "On screen" mark.** Decision: rows of the group drawn by the current visual (circular spectrum for Circular Spectrum, Camera, Photo, Video, Text; linear; particle orbit) say "On screen"; Glow is never marked (it is an effect, not a layer). The mark never filters or reorders.
- **UIX-009-D7 Values.** Decision: a row's value is the inspector target's current value through `ParameterValueText.display`, else "Read only" (no Settings control). Read at render; no observation beyond what SwiftUI tracks on AppSettings.
