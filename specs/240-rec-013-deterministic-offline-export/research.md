# Research: REC-013 Deterministic Offline Export

- **REC-013-D1 (clock)**: Decision: frame n is drawn at t = n × 1e9 / fps ns (integer) and the analysis has read the audio up to s(n) = (n × 44,100 + fps / 2) / fps samples. The recorder's frame grid (REC-006) puts a frame exactly on its slot, so every frame is admitted; `waitForPendingFrames` after each frame keeps the three-slot gate free, so none is dropped. Rationale: integer arithmetic gives the same times on every run; no real clock is read. Alternatives: pace with a timer (slow, nondeterministic); wall-clock stamps (rejected: the roadmap forbids real-time pacing).
- **REC-013-D2 (analysis)**: Decision: one `AnalysisPipeline` per export, created with the job's band count and a clock returning 0, attached to a `WaveformTap` around an `OfflinePCMSource`; per frame the source's limit moves to s(n) and `step()` runs synchronously (the worker timer is never started). The newest bus frame gives the bands and features (kept when no new spectrum completed); a second subscription's events drive the beat rings and particle visuals through the live triggers. Rationale: the exact live analysis, with no thread timing in the loop. Alternative: SpectrumAnalyzer directly (rejected: would skip the bus events the event-driven visuals need).
- **REC-013-D3 (projectM)**: Decision: projectM scenes are refused. PRE-005's `setFrameTime` pins the engine's clock, but presets also call the engine's own random number generator (`rand()` in the expression evaluator), which the app cannot seed through the public bridge; seeding it would be an engine patch (Constitution VIII: fork process, upstream PR). Camera, Photo, Video and Text are refused as live or external media. Alternative: export projectM with a warning that frames may differ (rejected: it would break the roadmap acceptance silently).
- **REC-013-D4 (checksums)**: Decision: SHA-256 (CryptoKit) of each frame's 8-bit BGRA bytes, top-down, tightly packed (width × 4 per row), read back from the rendered texture before encoding; lowercase hex. The audio is identified by the SHA-256 of its Float32 samples. Rationale: the encoded video is not bit-exact across runs (encoder internals), the rendered pixels are. Alternative: hash the MP4 (rejected), QA-002's `GoldenSHA256` (a test package not linked into the app).
- **REC-013-D5 (writer)**: Decision: `MetalFrameRecorder(realTime: false, audio: true)` with `RecordingSettings(maxFrameRate: fps, maxLongSide: 16_384, maxDurationSeconds: ceil(duration) + 1)`. Audio for frame n's interval [s(n), s(n+1)) is appended after the frame was appended, so both inputs advance together and the offline writer never waits for an input that is not coming. The audio timeline places contiguous chunks back to back (REC-004).
- **REC-013-D6 (fixture)**: Decision: a 10 s, 44.1 kHz stereo fixture generated from the seed: a 55 Hz kick with a 150 ms decay every 0.5 s (120 BPM), an A-minor chord (220, 261.63, 329.63 Hz) at 0.12 each, panned left/right, and a seeded noise hit (SplitMix64, 30 ms) on every off-beat with seeded level 0.1…0.3. Rationale: exercises bands, waveform, beats and onsets; small and repeatable.
- **REC-013-D7 (seed)**: Decision: the seed sets the fixture's noise and `ParticleFountainConfiguration.seed` / `ParticleOrbitConfiguration.seed` (UInt64(seed)). Nothing else in the export reads randomness.
- **REC-013-D8 (scope of the live look)**: Decision: the job carries what REC-002 carries (style, glow, Reduce flashing, clamp) plus the ANL-003 smoothing and the system Reduce Motion; audio-feature modulation (MOD), effect-quality steps (PERF-003) and the UIX-011 palette are not applied (the frames use the manual glow at full quality with the default palette, as REC-002's images). Rationale: those depend on live state or devices; leaving them out keeps the export repeatable.
- **REC-013-D9 (background)**: Decision: on `scenePhase` leaving `.active` while rendering, the coordinator cancels (iOS forbids background GPU work, which would fail the command buffers). Message "Export stopped: the app left the screen."
