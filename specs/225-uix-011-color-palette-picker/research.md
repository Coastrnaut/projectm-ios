# Research: UIX-011 Color Palette Picker

- **UIX-011-D1 — Model in SceneFormat.** The library codec must be readable by FILE-005 (LibraryBackup depends on SceneFormat) and by the app; SceneFormat is Linux-tested and already owns the scene links. Rejected: a new package (CI group, project.yml and docs-job changes for ~400 lines), VisualGenerators (LibraryBackup does not depend on it).
- **UIX-011-D2 — Links in `extra`.** SCN-001 keeps unknown layer and document fields verbatim, so `palette` on the document and on layers is read and written through `extra` accessors: no decoder change, no version bump, older apps keep the field. QA-004's meta-test covers error enums only; no case is added.
- **UIX-011-D3 — Rendering.** `VisualPalette` becomes an enum with a `custom(PaletteRamp)` case (stops in linear light + blended flag); `allCases` lists the four built-ins (all flash tests keep iterating them). Every generator already calls `color(bar:of:)` and recomputes colours on palette change (`!=`), so a new ramp value redraws without generator changes. Built-in IDs map to the existing cases so the default look is unchanged.
- **UIX-011-D4 — File format.** `{"format":"projectm-ios.palettes","version":1,"palettes":[{"id","name","style","colors":["#RRGGBB",…]}]}`, written canonically with SceneFormat's writer (sorted keys, deterministic bytes for FILE-005 digests). Lenient read (bad entries dropped and counted); a newer version is refused and never overwritten.
- **UIX-011-D5 — Colour names.** A small table of 16 named colours (VoiceOver names and the named-colour menu) and a nearest-name rule in HSL: low saturation → black/grey/white by lightness; else hue sector name with "dark"/"light" modifiers. Hex is always read after the name so the description is exact.
- **UIX-011-D6 — Contrast.** WCAG relative luminance of the sRGB swatch against black, `(L + 0.05) / 0.05`; under 3:1 (the ACC-003 bar threshold) is flagged.
- **UIX-011-D7 — Backup.** One archive record `palettes/palettes.json` (canonical file bytes) and per-palette plan entries `palette/<id>` in a new section `palettes`, following PRE-003's optional-record pattern (no backup format version change). Derived copy IDs: UUID from SHA-256("FILE-005|palette|<id>|<content sha256>|<n>").
- **UIX-011-D8 — Live updates.** The coordinator recomputes the effective `VisualPalette` when the library or the link changes and assigns it to the native host (as ACC-003 does); the compositor scenes' spectrum layer keeps the default (spec Assumptions).
