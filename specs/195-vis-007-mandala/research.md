# Research: VIS-007 Mandala Symmetry

- **VIS-007-D1 Band input.** The host already hands band-driven visuals ANL-002's bands (16 to 128, by the Bars setting the mandala does not show), smoothed by ANL-003. The mandala reduces them to three equal groups (low, mid, high; remainder to high) by mean, clamped to 0…1, non-finite → 0. The group means make the shape independent of the band count. VIS-001-R10's slew (`FlashSafetyLimiter.limitValues`) is applied to the bands first, as the circular spectrum does.
- **VIS-007-D2 Exact rotated copies.** Sector 0's points are computed once in the figure's local frame (angle measured clockwise from the top); sector k's points are sector 0's rotated by 2πk/N + ψ with the rotation matrix, using sines and cosines of 2πk/N computed once per symmetry. The test compares each sector with sector 0 rotated about the centre by 2πk/N within 1e-9 px (floating-point rounding is ~1e-13 at these magnitudes).
- **VIS-007-D3 Petal profiles.** t ∈ [0, 1] in 12 steps; radius ρ(t) = 0.08 + (ℓ − 0.08)·t; half-width angle h(t) = w·p(t)·σ (σ = half the sector or quarter with Mirror); centre offset c(t) = 0.35·high·t²·σ. Petal p = sin(πt), Round p = √sin(πt), Spike p = 1 − t. Each step is a quad (left/right at t_i, t_{i+1}): convex for these monotone profiles, triangles at a zero-width end. Max angular extent (0.6 + 0.35)·σ < σ, so petals stay in their sector or half-sector.
- **VIS-007-D4 Mirror.** Without Mirror the petal is centred at the sector centre (σ = π/N). With Mirror the petal is centred at the first half-sector's centre (σ = π/2N), and its reflection across the sector centre line forms the second half (vertex order reversed to keep the winding). Regions per sector: 12 (24 with Mirror).
- **VIS-007-D5 Rotation anchor.** ψ(t) = ψ_a + 2π·s·(t − t_a) with s the effective speed (min(configured, 0.05) / (Reduce Motion ? 2 : 1)); when s changes at a frame, (t_a, ψ_a) moves to that frame. Initially t_a = 0, ψ_a = 0, so with a constant speed ψ is a pure function of time. ψ is reduced mod 2π with the elapsed time computed in Int64 nanoseconds to keep precision.
- **VIS-007-D6 Flash model.** Quads are convex, inside the sector, never overlapping: `SpectrumFlashAreas` gets exact areas. Bands that jump from silence to full scale each frame change length, width and alpha at once; FX-019's gain bounds it (as VIS-005's waveform).
- **VIS-007-D7 Golden.** N = 6, Mirror off, Petal, bands low 0.6 / mid 0.5 / high 0.4 (a 48-band vector of three constant groups), time 0 (no rotation), glow off, Reduce flashing off, at both golden resolutions.
- **VIS-007-D8 Reduce Motion reach.** No native visual read Reduce Motion before. The coordinator already tracks `settings.systemReduceMotion` (ACC-001); it sets `NativeSpectrumHost.reduceMotion` when the host is made and whenever the system setting changes; the host applies it to the mandala's configuration.
