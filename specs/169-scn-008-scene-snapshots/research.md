# Research: SCN-008

- **SCN-008-D1 Contents.** The seven app-held MOD-001 parameters (`ParameterInspectorTargets.inspectableIDs`). They are the values Settings, the inspector and MIDI write, and none of them touches media. Rejected: FX-020 grade and trails (their own setters and ACC-012 caps; a later row can add them under a separate key), layer composites, text, the visual (would rebuild hosts).
- **SCN-008-D2 Storage.** Optional top-level `snapshots` array, entries verbatim (`fields`), values in the `parameters` form `{"kind", "value"}` so one codec serves both. Written only when set: older scenes keep their bytes, QA-004's matrix gains no row (format version 1).
- **SCN-008-D3 Lenient read.** As MOD-006/MOD-007: `SceneSnapshotEntry.read` returns one optional snapshot per position (nil = unusable) and warnings; positions past 16 are kept, unused, `invalidSnapshot`. A value with an unknown parameter ID keeps the snapshot usable; validation reports `unknownSnapshotParameter` per value (needs the registry). Decoder: more than 64 entries → `tooMany`.
- **SCN-008-D4 Recall plan.** Pure `SceneSnapshotRecallPlan(snapshot:registry:settable:)`: IDs in sorted order; unknown to the registry → skipped `.unknownParameter`; known but not settable by the app → `.notSettable`; else validated on a scratch `ParameterStore` (`set` clamps; a throw → `.rejected`). The app then writes only values that differ from the current ones.
- **SCN-008-D5 Undo.** `endCoalescing()`, the writes, then `SceneHistoryCoordinator.recordStep(label: "Recall <name>")` which captures the current inputs as one step with no coalescing key and closes coalescing. The observation callback that follows finds equal bytes and records nothing.
- **SCN-008-D6 Current scene list.** `SceneAutosaveCarry.snapshots` (as stored), read by `SceneAutosaveCoordinator.snapshotEntries`, replaced by `replaceSnapshots(_:)` which notes an edit and commits at once. The coordinator's observable `entries` reloads when the section appears.
- **SCN-008-D7 Media spy.** DEBUG lock-protected counters (`MediaLoadSpy`) at photo content set/preload, video content and loop-region set, logo set and photo/video host creation; a no-op in Release. Shown by a DEBUG probe in the snapshot status row for the UI test.
- **SCN-008-D8 Transition.** Recall is instant; easing over the scene's transition needs the CMP-014 bus in the renderer (SCN-007 follow-up).
- **SCN-008-D9 Trigger ID.** `SceneSnapshotEntry.recallActionID = "scene.snapshot.recall"` reserved; no binding reads it yet.
