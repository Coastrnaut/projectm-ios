# Contract: ANL-013 Stereo Correlation

- **C1 Meter.** `StereoCorrelationMeter.append(interleaved:frames:channels:)` with channels ≥ 2 reads channels 0 and 1 (others ignored; channels < 2 is ignored entirely). Non-finite samples count as 0. Every `blockFrames` frames (counted across calls) it updates: if either channel's block mean square ≤ floorMeanSquare, r = 0, `hasSignal` false and S, W are cleared; otherwise S ← a·S + block sums, W ← a·W + B and r = clamp(S_LR/√(S_LL·S_RR), −1, 1) (non-finite → 0). Identical channels give exactly 1, inverted exactly −1. The result depends only on the sample sequence, not on chunking; repeats are bit-equal. No allocation, lock, log or clock.
- **C2 Warning.** Per block: r < raiseBelow increments the raise counter (else it resets); r > clearAbove increments the clear counter (else it resets). Not raised and raise counter ≥ holdBlocks → raised; raised and clear counter ≥ holdBlocks → cleared. With L = R (mono, AUD-009 Left/Right/Mid/Side) r ∈ {0, 1}, so the warning never raises. `reset()` returns to `.none` and zeroes every sum and counter.
- **C3 Pipeline.** `AnalysisPipeline` feeds every accepted chunk to the meter before the mono mix; `AnalysisFrame.correlation` and `.phaseInverted` carry the reading; a session start resets it; `AnalysisPipelineConfiguration(correlation:)` must share the spectrum's sample rate (`sampleRateMismatch`).
- **C4 Source.** `AudioFeatureSource.correlation.id == "audio.correlation"`, parses back; value = clamp((r + 1)/2, 0, 1) of `AudioFeatureFrame.correlation` (nil or non-finite → 0). `CompiledExpression("audio.correlation")` emits opcode 34. `inspectorName == "Correlation"`.
- **C5 App.** `NativeSpectrumHost` passes r to the bindings and calls `onPhaseWarningChange(Bool)` on each change (false on start and stop when it was true). While raised, `SourceStatusIndicator.text` ends with " · Stereo channels look phase-inverted"; the overlay shows `stereo: r <value>[ phase-inverted]`. Raising posts X3a unless a raise was announced in the last 30 s; clearing posts X3b only when the raise was announced.
