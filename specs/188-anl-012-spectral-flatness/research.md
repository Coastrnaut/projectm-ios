# Research: ANL-012 Spectral Flatness

- **ANL-012-D1 Definition and weighting.** Decision: Wiener entropy over power, F = G/A, A = mean(P_k), G = exp(mean(ln(P_k + ε))), P_k = m_k². Rationale: the brief's definition; power matches ANL-010/011; for white noise each bin's power is exponentially distributed, so E[ln P] = ln A − γ and F → e^−γ ≈ 0.5615. Alternatives: magnitude flatness (noise reads ≈ 0.89, compressing the tonal/noise gap).
- **ANL-012-D2 ε.** Decision: ε = 10⁻¹²·A, computed after the total (two passes). Rationale: scale-invariant (F of k·P equals F of P exactly up to rounding), finite for zero bins, and negligible for real noise (the share of exponential bins below 10⁻¹²·A is ~10⁻¹²). A lone bin among K reads ≈ (10⁻¹²)^((K−1)/K)·K ≈ 10⁻⁹, i.e. 0; flat power reads 1 + 10⁻¹², clamped to 1. Alternatives: ANL-008's absolute 1e-20 (level-dependent near the floor; Float); excluding zero bins (a lone tone would read 1).
- **ANL-012-D3 Bins.** Decision: ANL-010's `SpectralBinRange` (20 Hz–Nyquist, DC excluded). Rationale: shared spectral-shape rule; its header already names ANL-012. ANL-008's private band breadth is not reused or changed (band-limited, Float, absolute floor).
- **ANL-012-D4 Scale.** Decision: linear F in 0…1 is published. Rationale: already bounded; a dB scale needs an arbitrary endpoint; formulas can reshape it (`sqrt`, `pow`). Alternative: n = 1 + 10·log10(F)/60 (rejected: arbitrary 60 dB span).
- **ANL-012-D5 Silence.** Decision: ANL-011's floor — Σ P_k / 1.5 ≤ 10^(−70/10) → F = 0, no signal; non-finite magnitudes count as power 0 (stay in K). Rationale: silence and dither must not read as noise; the brief asks for 0.
- **ANL-012-D6 Backends.** Decision: total via `vDSP_svesq` (Float) when Accelerate is compiled in and the backend is not `.portable`, falling back to the portable Double loop when non-finite; the log sum is a Double loop with `log` on both. Rationale: no scratch buffer (a vector log needs one); both paths differ only in A's rounding (~10⁻⁷ relative), well within 10⁻⁶.
- **ANL-012-D7 Opcode and name.** Decision: `audio.flatness`, opcode 33, inspector "Flatness". The brief suggested 20, but 20 is `min` (SHD-009) and opcodes 1–32 are all taken (19 = ANL-011 rolloff); no worktree claims 33 (checked 2026-11-14). Raw values are permanent, so a taken value cannot be reused.
