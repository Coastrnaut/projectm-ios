# Research: SHOW-004 Cue Transition Override

- **SHOW-004-D1 — Where the scene default lives.** Decision: SCN-007's per-cue `transition` is the scene default; the override is a separate optional field on the same cue entry. Rationale: SCN-007 already stores "how the cue's scene comes in" in the show and rejected the scene document; the SCN-007 sheet is what the brief calls the scene's default. A separate field means editing or removing the override can never touch the default (the acceptance), and "Use Scene Default" restores it exactly. Alternatives: a new `transition` in the SCN-001 scene document (schema change across QA-004's migration matrix, SCN-012, archives; and a third level next to SCN-007's) — rejected; a per-scene map in the show index like SCN-005 tags (also a third level) — rejected.
- **SHOW-004-D2 — What an "edge" is.** Decision: the edge into a cue (any step that makes it active). Alternatives: a from→to pair — rejected (Go to Cue, the scene switcher and MIDI/OSC have no single predecessor, and reordering would orphan pairs).
- **SHOW-004-D3 — Merge or replace.** Decision: the override replaces the whole default (type, duration, easing). Rationale: predictable; a partial merge would make a Cut override with a stored easing ambiguous.
- **SHOW-004-D4 — File field.** Decision: `transitionOverride`, the same object shape as SCN-007's `transition` (`duration`, `easing`, `type`), read with the same lenient `StoredTransition`; new warnings `droppedTransitionOverrides(Int)` and `unknownTransitionOverrideType(cue:type:)` so the existing SCN-007 counts keep their meaning. No version bump (SHOW-002 pattern).
- **SHOW-004-D5 — One resolution point.** Decision: `ShowCue.effectiveTransition` in ShowControl, used by `ShowCoordinator.show(_:)` for both the direct apply and the SCN-012 repaired-open closure. Every step source already runs through `perform` → `show` (SHOW-002 timed advances call `next()`, SHOW-003 runs `stepNow`), so no other call site changes.
- **SHOW-004-D6 — Editor.** Decision: reuse `CueTransitionView` with a `target` switch instead of a second sheet (same controls, same accessibility, smaller diff). Swipe label "Into" (short, fits beside Transition and Advance), accessibility label "Transition Into This Cue".
