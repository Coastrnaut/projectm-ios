# Research: SCN-011 Scene Template Gallery

- **SCN-011-D1 Content limited to what a cue shows.** Decision: circular spectrum, linear spectrum, text over circular spectrum, plus the seven app-held values. Rationale: SHOW-001-D5 applies only these; oscilloscope and Lissajous are not scene layers; bindings are not applied by a cue. Alternatives: an oscilloscope template (would show projectM instead), a kick binding (kept but inert) — rejected as misleading.
- **SCN-011-D2 Licensing.** Decision: no third-party asset; text written for the project; system font; MIT per repository `LICENSE`; manifest records every asset with SPDX `MIT` and a source. Rationale: Constitution IX, owner rule "no unlicensed media". Preset packs have their own licences and a scene cannot reference a preset anyway. Alternatives: preset-backed templates (licence per pack, not expressible) — rejected.
- **SCN-011-D3 Storage.** Decision: bundle folder resource `SceneTemplates/` with `manifest.json`; the catalog takes a directory URL so package tests read the repository copy through `#filePath`. Alternatives: Swift-built documents (not reviewable as files), a `.pmscene` archive (FILE-001; unneeded without media).
- **SCN-011-D4 Instantiation.** Decision: `SceneDocument.duplicated(newID:name:)` (SCN-003's path) and `ShowStore.saveScene` after an existence check; capacity checked first; one show save. Rationale: reuses the independent-copy path already proven; canonical bytes on disk.
- **SCN-011-D5 Preview.** Decision: an SF Symbol per template in the gallery; SCN-006 captures the copy's real preview at runtime after it is shown. Alternatives: bundled thumbnails (images to license and keep in sync) — rejected.
- **SCN-011-D6 Entry point.** Decision: Settings → Show "Add from Template…" only. Rationale: small change; the switcher (UIX-002) lists cues, not a library.
